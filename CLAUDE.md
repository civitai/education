# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Static Astro site for education.civitai.com, migrated from WordPress. README.md covers authoring
(front matter, embeds, heading anchors, pages) — read it before adding content.

## Commands

```sh
pnpm dev            # http://localhost:4321 (Pagefind search not built in dev)
pnpm build          # astro build && pagefind --site dist
pnpm check          # astro check (type-check); there is no test suite
pnpm preview        # serve dist/
pnpm check:urls     # against a running preview: every live WordPress URL must 200 or redirect to 200
                    #   pnpm check:urls -- --base https://education-new.civitai.com
pnpm export:wp      # re-export from the WordPress REST API; --cached re-converts from .cache/wp/
```

After changing a remark/rehype plugin, delete `node_modules/.astro/` — Astro caches rendered Markdown.

## Architecture

**URL compatibility is the core constraint.** Every public WordPress URL must keep working:
`trailingSlash: 'always'`, `build.format: 'directory'`, posts and pages both at `/<slug>/`
(`src/pages/[slug].astro`), archives at `/category|tag|author/<slug>/` with `…/page/N/` pagination
(`[...page].astro`), feeds at `…/feed/` (served as `feed/index.html.ts`), and Yoast-named sitemaps
(`*-sitemap.xml.ts`). `src/lib/content.ts` builds the merged slug map and throws on post/page clashes.
Reading settings (front page = `home` page, posts page = `/civitai/`, per-page count) live in
`src/lib/site.ts`.

**Content pipeline.** `src/content/posts|pages/*.md` (schema in `src/content.config.ts`) is mostly
generated by `scripts/export-wp.mjs`. Exported files carry a `wpId`; the exporter rewrites/removes
only those, so hand-written files (no `wpId`) are safe. The exporter also writes
`src/data/taxonomies.json`, `src/data/wp-ids.json` and `public/_redirects`.

**Markdown processing** (`astro.config.mjs`) uses the unified remark/rehype processor, not Astro's
default, so custom plugins run: `remark-directive` + `remark-callouts` (`:::note|tip|warning|caution`),
`remark-heading-id` (`{#id}`), `rehype-raw` (must precede embeds), `rehype-embeds`, `rehype-table-wrap`.
`smartypants` is off on purpose (prompts and `--flags` must stay literal).

**Embeds.** Content contains `<div data-embed="…">` placeholders; `src/lib/rehype-embeds.mjs` is the
single place that decides their markup. VideoPress guids found in `src/data/videopress.json` render as
self-hosted `<video>` from `/videos/<guid>/<file>`; unknown guids fall back to the VideoPress iframe.

**Deployment** is nginx in-cluster, not Cloudflare Pages (see `Dockerfile`). `public/_redirects` is
kept in Cloudflare format as the source of truth; `scripts/build-nginx-conf.mjs` converts it plus
`wp-ids.json` into `maps.conf` (WordPress `?p=` / `?page_id=` shortlinks) and `redirects.conf`,
included by `nginx/default.conf`. That config also proxies `/wp-content/` and `/videos/` to a
Backblaze B2 bucket, so media URLs in content still use WordPress paths but are served from B2.
