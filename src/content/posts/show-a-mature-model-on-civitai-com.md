A model you mark as mature stays off civitai.com. civitai.com shows only PG and PG-13 content, so a mature model has no listing there, even if some of its images are tame. The **civitai.com tab** in the model editor changes that. You write a separate title, description and cover for civitai.com, and the same model then shows on both sites. You do not upload a second model.

## What you get {#what-you-get}

- On **civitai.com**, people see your civitai.com title, description and cover. They see only the model's PG and PG-13 images.
- On **civitai.red**, nothing changes. People who have mature content turned on see your original title, description and cover.
- The model keeps its mature mark. The civitai.com listing is an extra face on the same model, with the same files, versions and downloads.

Use it when you made a model for civitai.red and want civitai.com visitors to find a clean version of its page. If your model is not mature, you do not need it, because both sites already show it.

## Who sees which listing {#who-sees-what}

The listing follows the viewer's browsing level, not only the site they are on.

| Viewer | Sees |
|---|---|
| Anyone on civitai.com, signed in or not | The civitai.com listing |
| Anyone signed out on civitai.red | The civitai.com listing |
| Someone on civitai.red with mature content turned off | The civitai.com listing |
| Someone on civitai.red with mature content turned on | The original civitai.red listing |

You and moderators can open both listings in the editor.

## What the civitai.com tab sets {#what-it-sets}

Only three things can differ between the sites: the **title**, the **description** and the **cover**. Everything else about the model is shared, such as its files, versions, type, tags and permissions.

While a model has its own civitai.com listing, civitai.com does not show its version descriptions. Version names and trigger words are shown as they are, so keep them clean.

## Set it up {#set-it-up}

1. Open your model in the model editor, the same place where you mark a resource as mature. (This step has not been checked against the live site yet.)
2. In the **Title, description & cover** box, you will see two tabs, **civitai.red** and **civitai.com**. The civitai.red tab holds your original title, description and cover.
3. Open the **civitai.com** tab. Until you write something, it says civitai.com shows the same title and description as civitai.red, and the tab carries a **Same as .red** badge.
4. Choose **Write a civitai.com version** to start from a copy of your current text, or **Draft a civitai.com version** to have a clean rewrite made for you. The draft is only a suggestion. Nothing is saved until you save the model. If you already have different civitai.com text, you are asked before the draft replaces it.
5. Edit the **Title** and the **Description**. A line above each field checks the text as you type and tells you if it reads as too mature for civitai.com. Leave the description empty if you want civitai.com to show none. The civitai.red description is never shown there instead.
6. Pick a **Cover** for civitai.com. Only your own images rated PG or PG-13, published on this model, are offered. Click the picked image again to clear it. The picker appears once the model exists. If it says none of your images are rated PG or PG-13 yet, or asks you to publish a post with images on the model, do that first.
7. Save the model to publish your changes. As soon as the tab holds your own text (after step 4), it shows an **Own content** badge instead of **Same as .red**.

To go back, choose **Use the civitai.red listing** in the civitai.com tab and confirm. The civitai.com title, description and cover are removed, and civitai.com shows the same listing as civitai.red.

## When the model appears on civitai.com {#when-it-appears}

A mature model shows on civitai.com once its civitai.com listing is complete. That means:

- a civitai.com **title**, and
- a civitai.com **cover**: one of your own images, rated PG or PG-13, that is scanned, not flagged, and sits on a published post on a published version of the model.

The description is optional.

If the cover stops qualifying, for example the image or post is deleted, moderated or re-rated, or the version is unpublished, the model leaves civitai.com again. Pick a new cover to bring it back.

## Checks and review {#review}

Civitai checks the civitai.com title and description with the same text scan that helps decide whether a model is mature. A title or description rated above PG-13 cannot be saved. You also cannot save while the check is unavailable, so try again a little later. No one has to approve your civitai.com listing before it goes up.

## Questions {#faq}

**Do I need to upload the model twice?**
No. It is one model with two listings.

**Does the civitai.com listing change the mature mark?**
No. The model stays mature and keeps its standing on civitai.red.

**Why is my mature model not on civitai.com yet?**
It needs a civitai.com title and a qualifying PG or PG-13 cover. Check the civitai.com tab for both.

**Why does the model not show up in the generator on civitai.com?**
Version levels are not changed. Mature versions stay out of safe-for-work places such as the generator's resource picker on civitai.com.

**Which images do civitai.com visitors see on the model page?**
Only the model's PG and PG-13 images.

**Why does my own model page on civitai.com show the civitai.red title?**
Owners and moderators get both listings, because the same page fills the editor. Switch tabs in the editor to see the civitai.com version. Everyone else sees only the one that matches their browsing level.
